Functions

Functions are one way of creating reusable code in Breve. They are declared as follows:

<name> :: (<arg>, ...) -> <type>

And can be followed by => and an expression, { ... } for a code block, or nothing, for forward declarations. For each part:

<name> the function's name, and follows the same rule as the variable's name. Required.

<arg> is a function argument. These are declared like variables. If more than one, each argument must be separated by a comma. If an argument has a default value, that argument must be placed after all required arguments. Optional.

<type> is the function's return type. Optional for non-forward declarations, defaults to auto-deducing the type.

Thusly, a function can be declared like the following:

// Declaring the function here, code comes later
doNothing :: () -> void

// Declaring a single-line function
square :: (num: float32) -> float32 => num * num

// Declaring a full function
factorial :: (num: uint64) -> uint64 {
    out = 0
    for i : 0 ... num
        out += i + 1
    return out
}

And many other possible ways.

External Functions

External functions are your way of calling cross-language code. They come in two types: Out Functions and Shared Functions.

ART Functions are one way of calling cross-language code. ART functions execute code that is defined by the ARTE implementation.

Declared via the @ARTCall(name = "<addr>") attribute, followed by how one would forward declare a function.

Shared Functions, much like ART functions, are also for calling cross-language code. Unlike their siblings, however, shared functions execute code defined in an Anima-compatible shared library.

Declared via the @Shared(lib = <libpath>, name = "<addr>") , followed by how one would forward declare a function.
