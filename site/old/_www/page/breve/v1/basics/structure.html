Code Structure

If you open a new project`s main.bv file in your text editor, you should see the following:

using import core

@Main
main :: () {
    // Main code goes here...
    IO.writeLine("Hello, World!")
}

Let`s break the code down and explore it, line-by-line.

using import core: An using import statement. These will be discussed later, but essentially → this is how you import modules and files.

@Main: An attribute. What these are and what they do will be explained further ahead. In this case, this one designates that the given function is the main entypoint for the program.

main :: () {: A function. Where code actually gets run. Since this function has the @Main attribute, it is considered the entrypoint for the program. An entrypoint is required for programs, and ignored for modules.

// Main code goes here...: A line comment. Does not get executed, and only serves for documentation, or little notes. Block comments can be declared via /* ... */.

IO.writeLine("Hello, World!"): An expression. Expressions are the building blocks of your program. In this case, this expression calls the function writeLine, that lives in the namespace IO, with the string"Hello, World!". All of these concepts will be explained later.
